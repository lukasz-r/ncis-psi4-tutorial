# Tutorial: Analysis of Non-Covalent Interactions with Psi4

## For *Fundamental Insights to Weak Interactions: Interplay of Theory and Spectroscopic Experiments. Confined Astrochemical Microenvironments — from Gas to Ice, Dust and Planetary Soils* (COST COSY Training School, Iława 2026)

We demonstrate how to use basic quantum chemistry methods available in [Psi4](https://psicode.org/) computational chemistry package for quantitative description of non-covalent interactions.
